# LangGuard public code

This repository holds code that LangGuard customers deploy in their own environment. Each directory is one package with its own README.

Claude Code, Codex, Cursor and Antigravity plugins are in [langguard-plugins](https://github.com/LangGuard-AI/langguard-plugins).

The LangGuard documentation is at [docs.langguard.ai](https://docs.langguard.ai).
